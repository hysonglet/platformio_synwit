# platform-synwit

English | [中文](README.md)

A [PlatformIO](https://platformio.org/) development platform for **Synwit (华芯微特) SWM series** ARM Cortex-M microcontrollers.

The platform is intentionally thin and **data-driven**: `platform-synwit` only provides board definitions, build/upload scripts and the import tool. Every chip-specific detail (core, Flash/RAM, include and source paths, linker script, SVD, optional libraries, clock presets) lives in `framework-synwit/mcu.json` next to this repo. Adding a device means adding data, not code.

- 10 series / 15 devices, all verified with real builds
- Vendor Chip Support Library (CSL) + CMSIS-Core, ready to use with GCC / newlib
- Clock tree, optional libraries (CMSIS-DSP, USB-Host) and linker script configurable from `platformio.ini`
- One blink example per series, plus RTT, LVGL and offline map examples

## About Synwit

[Synwit (华芯微特)](https://www.synwit.cn/) is a Chinese fabless semiconductor company founded by a senior technical team returned from overseas study in the US, and a certified National High-Tech Enterprise. It entered the MCU market in 2014 and focuses on the design of **32-bit MCUs**, together with reference solutions for specific market segments. Its official site is <https://www.synwit.cn/>.

The core team has more than ten years of chip-design experience, with deep expertise in CPU, memory, low-power processors, AD, POWER and ESD, and holds over 100 independent intellectual-property rights. Its chips are based on ARM® Cortex®-M0 / M4 / M33 cores (including Arm China's STAR-MC1) and target **TFT-LCD display control, motor control, home appliances, smart control and industrial instrumentation**, with a strong emphasis on reliability and stability. The company's vision is "to become a leading semiconductor company in display driving and motor control", under the motto "a Chinese heart, a world-class chip".

The SWM series supported by this platform is Synwit's 32-bit MCU line. The SWM341 (Cortex-M33 with TFT-LCD control) is a representative display-driver device; see the LVGL examples for 800×480 RGB panels in [`swm341-lvgl-rtt`](examples/swm341-lvgl-rtt/) and [`swm341-lvgl9.5-map`](examples/swm341-lvgl9.5-map/).

## Repository layout

```
platform-synwit/
├── platform.json               # platform metadata: framework, toolchain, packages
├── platform.py                 # auto-detects the sibling framework-synwit, resolves SVD paths
├── boards/                     # 15 board JSONs (generated by tools/import_csl.py)
├── builder/
│   ├── main.py                 # build / .bin / .hex / upload targets
│   └── frameworks/
│       ├── _bare.py            # common bare-metal build flags
│       └── synwit.py           # reads mcu.json and builds the CSL static libraries
├── tools/import_csl.py         # imports the vendor SDK and generates the data above
└── examples/                   # example projects (see examples/README.md)
```

The companion `framework-synwit/` sits next to `platform-synwit/` and holds `csl/` (vendor peripheral library), `mcu.json`, `ldscripts/` and `svd/`.

## Installation

### Prerequisites

- [PlatformIO Core 6](https://docs.platformio.org/en/latest/core/index.html) (check with `pio --version`)
- Python 3 (bundled with PlatformIO, used by the platform scripts)
- The GCC ARM toolchain is downloaded automatically

### From the Git repository

```bash
pio pkg install --global --platform https://github.com/hysonglet/platformio_synwit.git
```

This pulls `framework-synwit@~1.0.0` from the PlatformIO registry (it must be published there).

### Verifying the installation

```bash
pio pkg list --global          # the synwit platform should appear
pio boards synwit              # lists all 15 boards
pio platform show synwit
```

## Quick start

```bash
cp -r examples/swm341-blink /tmp/my-swm341 && cd /tmp/my-swm341
pio run                       # build every env in this project
pio run -e swm341xe           # build a single chip
pio device monitor            # serial console, 57600 8N1
```

A minimal `platformio.ini`:

```ini
[env:swm341xe]
platform = synwit
framework = synwit
board = swm341xe
monitor_speed = 57600
```

The blink examples use the pins of Synwit's own evaluation board (LED = PA5; see `examples/README.md` for UART0 pins). Adapt them at the top of `main.c` for your own board.

## Project options

All options go into `platformio.ini` and map to `build.*` in the board JSON:

| Option                                       | Description                                                             |
| -------------------------------------------- | ----------------------------------------------------------------------- |
| `board_build.synwit_clock`                   | Clock tree: a preset name from `mcu.json`, or any `NAME=VALUE` list     |
| `board_build.f_cpu`                          | Value fed to `F_CPU`; **update it manually when you change the preset** |
| `board_build.synwit_features`                | Extra optional libraries: `dsp` (SWM320/341), `usb_host` (SWM341)       |
| `board_build.float_abi`                      | `soft` (default, matches the vendor Makefile) / `softfp` / `hard`       |
| `board_build.ldscript`                       | Override the default linker script                                      |
| `board_build.synwit_<lib-short-name>_filter` | Override a library's `src_filter`, e.g. `synwit_csp_filter`             |

Presets are derived automatically from the `SYS_CLK_xxx` constants in `system_<chip>.c`, plus `vendor_default`. To list all presets of a device:

```bash
python3 -c "import json;print(*sorted(json.load(open('../framework-synwit/mcu.json'))['families']['swm181xc']['clock_presets']),sep='\n')"
```

SWM341 also provides `xtal12m` and `pll_xtal12m_120m` (12 MHz crystal → 120 MHz PLL):

```ini
board_build.synwit_clock = pll_xtal12m_120m
board_build.f_cpu        = 120000000L
board_build.synwit_features = dsp
```

## Flashing and debugging

`pio run` only builds. The upload path has not been validated on hardware end to end; the interfaces are in place:

1. `upload_protocol = custom` with `upload_command=...` to call a vendor tool (SWMTool / SynwitPRG / J-Flash). The advanced SWM341 examples above use `probe-rs run --chip swm341`.
2. `upload_protocol = jlink`: J-Link first needs device support. Synwit ships per-series `.FLM` files in `01.开发环境搭建(入门必备)/04.Segger J-Link 套件/Synwit_JFLASH-241126.zip`; drop them into `Devices/Synwit/` and register them in `JLinkDevices.xml`. `tool-jlink` is declared in `platform.json` but is dropped automatically when nobody selects J-Link, so it does not cost ~40 MB for nothing.

Debug SVDs ship with the framework package; `platform.py::_add_series_debug()` resolves `debug.svd_path` to an absolute local path.
